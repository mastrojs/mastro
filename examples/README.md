A collection of Mastro example projects.

When checked out as part of this monorepo, the examples use the Mastro version from [../libs/mastro/](../libs/mastro/) via pnpm workspaces, which is helpful for Mastro development.

[basic-node](basic-node), [basic-bun](basic-bun), [basic-cloudflare](basic-cloudflare), and [blog](blog) are used as templates in [create-mastro](../libs/create-mastro/) and therefore need to work stand-alone as well.
